# ETL — Rampap Marketing Campaigns

Skill for running the ETL (Extract, Transform, Load) process on MRP data exported from
Sankhya into Rampap's PRs Campaign template.

## When NOT to use

- For analysis of data already loaded into the template — use analysis skills (future)
- For generating charts or presentations — use reporting skills (future)
- For manually editing campaign data (PRx, IT PRx, Inc PRx)

## Process overview

The ETL takes two files:
1. **MRP export** — Excel file generated by the Sankhya MRP screen (single sheet, ~6,000 rows, 89 columns A-CK)
2. **Campaign template** — Excel file with 18 tabs (`MRP ativos`, PRx, IT PRx, Inc PRx)

The result is the campaign template populated with the filtered MRP data.

## Prerequisites

- Python 3.8+ with `openpyxl` installed (`pip install openpyxl`)
- Both Excel files in the same folder or at accessible paths

## Step by step

### Step 1: Identify the files

Ask the user (if not already provided):
- Path to the **Sankhya MRP export** (file with a single sheet named `new sheet`)
- Path to the **campaign template** (file with tabs `MRP ativos`, `IT PR1`, etc.)

If the user provides only one file, identify which it is by its content:
- MRP export: single sheet named `new sheet`, row 1 contains "arquivo", row 2 contains "Emissão:"
- Template: multiple tabs including `MRP ativos`, `IT PR1`, `Template`, `Racional`

### Step 2: Run the ETL script

Run the bundled script `scripts/etl_mrp.py`, passing the file paths:

```bash
python <skill-path>/scripts/etl_mrp.py --mrp "<mrp-export-path>" --template "<template-path>" --output "<output-path>" --lang "<user-language>"
```

The script performs all transformations automatically. If the user does not specify the
output path, generate the file in the same folder as the template with an `_ETL` suffix.

Pass `--lang` with the user's preferred language so the script's progress/summary logs are
emitted in that language (supported: `pt-BR`, `en`; default: `pt-BR`).

### Step 3: Validate the result

After execution, report to the user:
1. How many rows the MRP export originally had
2. How many rows ended up in **`MRP ativos`** (after the Ativo = "N" filter)
3. How many rows ended up in **`IT PR1`** (after the Em ruptura = 1 filter)
4. Whether the calculated columns (CL-CT) of `IT PR1` were preserved

Report in the user's preferred language.

### Step 4: Make it available for analysis

Tell the user the template is ready and suggest next steps:
- Review the data in Excel
- Use campaign analysis skills (when available)
- Generate reports or presentations

## ETL technical details

For reference, the `etl_mrp.py` script performs these steps:

### Extract
1. Open the Sankhya MRP export
2. Skip the first 2 rows (metadata: "arquivo", "Emissão:...") and the last row
3. Row 3 contains the real headers (89 columns, A through CK)
4. Rows 4 onward are the data

### Transform
5. Filter: keep only rows where column **BP ("Ativo") = "N"** (inactive products)
6. From the result above, create a second filter: keep only rows where column **CF ("Em ruptura") = 1**

### Load
7. Open the campaign template
8. In the **`MRP ativos`** tab: clear existing data (A2 to CK), preserve the header (row 1), paste data filtered by Ativo = "N"
9. In the **`IT PR1`** tab: clear existing data (A2 to CK), preserve the header (row 1), paste data filtered by Em ruptura = 1
10. Preserve all other tabs intact (Template, Racional, PRx, IT PR2-5, Inc PRx)
11. Preserve formulas in the calculated columns of IT PR1 (CL through CT) — the script only pastes into columns A-CK

## Column headers in the generated file

The generated spreadsheet's column headers (row 1) are **inherited verbatim from the campaign
template** — the script preserves row 1 and only writes data into rows 2+. They are not
localized, because they double as data identifiers tied to the MRP/Sankhya source and to
`references/data_schema.md`. Only the script's runtime logs follow the user's preferred language
(via `--lang`); the artifact's headers stay as the template defines them.

## Campaign template structure

| Tab | Content | Modified by the ETL? |
|-----|---------|----------------------|
| Template | Introductory text | No |
| Racional | Campaign methodology | No |
| **MRP ativos** | Product catalog (Ativo="N") | **Yes** |
| PR1-PR5 | Description of each campaign | No |
| **IT PR1** | Campaign 1 items (Ruptura=1) | **Yes** |
| IT PR2-PR5 | Campaign 2-5 items | No |
| Inc PR1-PR5 | Increment summaries | No (recalculated via formulas) |
